Date

This example shows ObDateComponent, which renders a date or a time in an accessible way following the given format and timeFormat inputs. The result follows locale preferences expressed by the language selected in the top right corner but always renders the day before the month (except for isoDate). The explanations are intentionally left in English to keep the example simple and let you focus on the real purpose: the date formats.

Accepted date input

The date input accepts an ISO or Swiss date string, a Date object, or a timestamp. All examples below use the default format.
